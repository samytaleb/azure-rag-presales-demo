# MeridianOps — Implementation and support (SYNTHETIC)

> Fictional demonstration policy, not a contractual commitment.

## Pilot checklist
1. Confirm target use case, data ownership and decision maker.
2. Select a sandbox dataset and establish a success criterion.
3. Validate CSV structure or REST API mappings.
4. Test dashboards with a representative sample.
5. Review security and access constraints with the customer.
6. Capture pilot feedback and agree on production prerequisites.

## Pilot definition of done
A pilot is complete when a stakeholder can reproduce the approved dashboard on synthetic or authorized data, identify at least one actionable insight, and trace that insight to an input source.

## Support
- Growth support hours: **Monday–Friday, 09:00–17:00 UTC**.
- Growth initial response target: **8 business hours**.
- Enterprise initial response target: **4 business hours** during agreed support hours.
- No **24/7** support commitment or contractual uptime SLA is given in this sample.

## Integration acceptance
New sources require schema mapping, authentication design, a test plan and ownership sign-off. No automatic CRM updates are permitted by the baseline design.
