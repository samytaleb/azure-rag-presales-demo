# MeridianOps — Product overview (SYNTHETIC)

> Demonstration-only document. MeridianOps and its policies are fictional, created for this portfolio. No SAP or customer information is included.

MeridianOps is a fictional B2B revenue-operations analytics platform for small and medium-sized teams. It provides dashboards for account portfolio analysis, forecasting and opportunity prioritization. It is **not** a transactional CRM and **does not** write changes back to CRM records.

## Supported input sources
- CSV import of up to **50,000 rows per file**.
- REST API ingestion for accounts and opportunities; source data refresh is scheduled **hourly**, not real-time.
- Manual CSV export of analysis results.

## Plans
MeridianOps has three fictional plans: Starter, Growth and Enterprise. Plan details are in `02-pricing.md`.

## Limitations
- No native Salesforce write-back.
- No guaranteed real-time sync.
- No built-in contact-data enrichment from third-party providers.
- Generated recommendations must be reviewed by a human before customer-facing use.

This document is not a statement about any actual commercial product.
